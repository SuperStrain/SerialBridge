# 新需求设计文档：串口日志本地保存（设计稿 v2，已按用户要求调整，待批准）

> 状态：**待用户批准，未实施**
> 需求来源：监控窗口仅保留最近 3000 条缓存、导出为手动操作——需要**持续、完整、自动**的串口数据落盘能力。

---

## 1. 需求目标

1. 每条映射可独立开启"串口日志"，串口数据流**持续完整落盘**（参考 Xshell 日志体验）。
2. **用户自选存储路径**：开启日志开关时立即弹出文件夹选择对话框。
3. **文本记录为默认**（ASCII / UTF-8），可选其他格式（GBK 编码、HEX 无损模式）。
4. 长期运行友好：按天轮转、单文件上限、按保留天数自动清理。

---

## 2. 记录模式与编码（对 v1 的关键调整）

原文档采用"HEX+ASCII 双向带方向标记"的行格式。按用户新要求调整为**两种模式**：

### 2.1 文本模式（默认，Xshell 式会话日志）

- **仅记录 OUT 流（设备→网络）**：设备输出的全部内容（含对用户输入的回显），
  解码后**以正文形式连续写入**——日志文件打开即是完整的终端画面，无任何标记噪音
- **编码可选**：
  - **UTF-8（默认）**：设备字节**原样写入**（零转换、零损失，适合 Linux shell/UTF-8 设备）
  - **GBK**：字节按 GBK 解码后以 UTF-8 写入（适配 GBK 编码的老设备/中文模块）
- 适用：shell 交互、AT 命令、文本协议
- ⚠️ 说明：二进制协议（含 0x00/图形字节）在文本模式下会出现替换符——此类场景请用 HEX 模式

### 2.2 HEX 模式（可选，协议分析用）

- **双向记录**（OUT/IN 都记），每条一行带时间戳、方向、字节数：

  ```
  2026-10-11 14:20:30.123 OUT 11 48 65 6C 6C 6F | Hello
  2026-10-11 14:20:30.456 IN  5  31 32 33 0D    | 123
  ```

- HEX 段记录**完整字节**（无损还原通信）；ASCII 段仅截断显示前 64 字节
- 不可打印字符显示为 `·`；文件编码固定 UTF-8

### 2.3 模式与方向约定

| 模式 | 记录范围 | 方向标记 | 典型用途 |
|---|---|---|---|
| 文本（默认） | 仅 OUT（设备输出，含回显） | 无（连续正文） | 会话留痕、shell 交互 |
| HEX | OUT + IN 双向 | 有（OUT/IN 标签） | 协议分析、二进制调试 |

> 理清的"矛盾"：文本模式下 IN（用户下发）不写入正文——因为设备的回显（OUT）已经
> 包含了用户输入的可见内容，再记 IN 会造成重复与正文断行。需要审计下发内容时用 HEX 模式。

## 3. 存储位置与文件组织（对 v1 的关键调整）

### 3.1 用户自选目录

- **开启"串口日志"开关时，立即弹出文件夹选择对话框**（参考 Xshell 日志存储），
  用户指定该映射的日志目录；路径显示在开关下方，可随时"更改路径"
- 目录按映射隔离（每条映射各自目录，默认建议 `%AppData%\SerialBridge\captures\<映射名>`）
- 路径失效（U 盘拔出/目录被删）时：自动重建目录；失败则降级暂停并告警

### 3.2 文件命名与轮转

```
<用户选择目录>    ├── <映射名>_20261011.log
    ├── <映射名>_20261012_002.log      ← 单日超 50MB 时的同日分卷
    └── ...
```

| 策略 | 默认值 | 说明 |
|---|---|---|
| 按天轮转 | 开 | 文件名含日期 |
| 按大小轮转 | 50 MB | 超限滚动为同日分卷 `_002`、`_003` |
| 保留天数 | 30 天（7–365 可配） | 启动时 + 每天清理过期文件 |
| 磁盘余量保护 | 500 MB | 低于阈值暂停记录并告警，恢复后继续 |

- 映射删除时**历史日志保留**（用户确认）。

## 4. 性能与可靠性

1. **异步写入**：专用写任务 + 队列（2048 块）；转发路径仅入队+一次复制（微秒级）。
2. **批量落盘**：500ms 或缓冲 64KB 时 flush。
3. **队列溢出**：丢弃最旧未写块、计数告警（保护通信主链路优先）。
4. **IO 异常降级**：写失败自动暂停记录 + 告警状态，30s 重试；转发不受影响。
5. **退出安全**：退出时 flush 并关闭句柄。

## 5. 配置与界面

### 5.1 映射配置

```jsonc
// MappingConfig 新增
"DataLog": {
  "Enabled": false,          // 开启时弹出目录选择
  "Directory": "",           // 用户选择的存储路径（必填才生效）
  "Format": "Text",          // Text（默认）/ Hex
  "Encoding": "UTF-8",       // 文本模式：UTF-8（默认）/ GBK
  "RetentionDays": 30,
  "MaxFileMB": 50
}
```

### 5.2 界面

| 位置 | 内容 |
|---|---|
| 编辑对话框"串口日志"分组 | 启用开关（**开启即弹出目录选择**）；路径显示 + 更改按钮；格式（文本/HEX）；编码（UTF-8/GBK，仅文本模式可见）；保留天数；单文件上限 |
| 映射卡片 | 状态徽标：`● 记录中`（+当前文件名）/ `⚠ 日志暂停`（异常）/ `⚠ 日志路径未设置` / 不显示（未启用）；点击徽标打开日志目录 |
| 设置窗口 | "打开数据日志目录"快捷入口 |
