# 开发者编译与打包说明

## 环境要求

| 工具 | 版本 | 用途 |
|---|---|---|
| .NET SDK | 8.0.x（LTS） | 编译 |
| Inno Setup | 6.5+ | 制作安装包（另需 `ChineseSimplified.isl` 放入脚本同目录） |
| Git | 任意 | 版本管理 |

## 项目结构

```
SerialBridge/
├── SerialBridge.sln
├── src/
│   ├── SerialBridge.Core/          # 核心逻辑（无 UI 依赖，可单测）
│   │   ├── Models/                 #   MappingConfig / AppSettings / 枚举
│   │   ├── Serial/                 #   串口会话（打开/读循环/重连/写串行化）
│   │   ├── Tcp/                    #   TCP 监听与客户端连接（发送队列/慢客户端保护）
│   │   ├── Bridge/                 #   MappingRuntime 双向转发与统计
│   │   ├── Management/             #   MappingManager 互斥检查与生命周期
│   │   ├── Config/                 #   JSON 持久化与串口枚举
│   │   ├── Logging/                #   Serilog 初始化
│   │   └── Net/                    #   本机网卡信息
│   └── SerialBridge.App/           # WPF 界面（MVVM，WPF-UI Fluent）
│       ├── Views/                  #   主窗口 / 映射编辑 / 数据监控 / 设置
│       ├── ViewModels/             #   CommunityToolkit.Mvvm
│       ├── Services/               #   AppServices / 防火墙 / 开机自启
│       └── Themes/                 #   语义色与样式
├── tests/SerialBridge.Core.Tests/  # xUnit 桥接行为测试（含假串口设备）
├── installer/SerialBridge.iss      # Inno Setup 脚本
└── docs/                           # 用户说明 / 本文件 / 测试记录
```

## 常用命令

### 调试运行

```bash
dotnet build -c Debug
dotnet run --project src/SerialBridge.App
```

### 单元测试（无需真实串口硬件）

```bash
dotnet test tests/SerialBridge.Core.Tests
```

测试通过 `FakePortStream`（内存管道模拟串口设备端）+ 真实 TCP Socket 覆盖：双向透传与顺序、二进制完整性、单客户端拒绝、多客户端广播、写串行化、慢客户端断开、断线重连、串口热插拔重连、端口占用、端口冲突、资源释放。

### 发布（self-contained，无需目标机安装 .NET）

```bash
dotnet publish src/SerialBridge.App -c Release -r win-x64 --self-contained true -o dist/publish
```

### 打包安装程序

```bash
# 前置：将 ChineseSimplified.isl 放到 installer/ 目录
ISCC.exe installer/SerialBridge.iss
# 产物：dist/installer/SerialBridge-Setup-1.0.0-x64.exe
```

Inno Setup 的 `ChineseSimplified.isl` 可从
<https://github.com/jrsoftware/issrc/blob/main/Files/Languages/Unofficial/ChineseSimplified.isl> 下载。

### 一键完整构建（PowerShell / Git Bash）

```bash
dotnet test tests/SerialBridge.Core.Tests \
 && dotnet publish src/SerialBridge.App -c Release -r win-x64 --self-contained true -o dist/publish \
 && ISCC.exe installer/SerialBridge.iss
```

## 版本升级注意

1. 更新 `src/SerialBridge.App/SerialBridge.App.csproj` 中的 `Version` 与 `installer/SerialBridge.iss` 中的 `AppVersion`。
2. 配置文件带 `Version` 字段（`AppSettings.CurrentVersion`），未来格式变更时在 `ConfigStore.Sanitize` 中做迁移。
3. 升级安装不触碰 `%AppData%\SerialBridge`，用户配置自动保留。

## 关键设计说明

- **读串口**：使用同步 `SerialPort.Read` 放在线程池执行（`ReadTimeout` 抛 `TimeoutException` 轮询）。
  不要改回 `BaseStream.ReadAsync`——其 APM 路径在超时时抛 `IOException(ERROR_OPERATION_ABORTED)`，会被误判为设备移除。
- **慢客户端保护**：每个 TCP 客户端有 256 条的发送队列（Channel bounded），串口数据入队不阻塞读循环；
  队列满即视为慢速客户端并主动断开，避免内存无限增长。
- **写串口串行化**：串口写单次 `Write` 原子提交，多客户端数据按到达顺序写入，不会交叉。
- **互斥检查**：同一物理串口或同一 `IP:Port` 不可被两条运行中的映射同时占用（`MappingManager.ValidateNew`）。
- **UI 不阻塞**：所有串口/网络 IO 异步；监控界面采用批量刷新（150ms）+ 限量缓存（3000 条）。

## 已知限制（第一版）

- 不含虚拟 COM 驱动、RFC 2217、加密与身份认证。
- 串口热插拔依赖读写异常检测（毫秒级感知），未实现 WMI 即插即用通知。
- 多客户端模式下不同客户端的请求/响应配对需由上层协议保证。
