# 串口终端快捷命令与宏

在主界面打开目标映射的「串口终端」，点击顶部 **快捷命令 / 宏**。

- 一个预设包含一个步骤时即为常用命令快捷发送；包含多个步骤时按顺序运行宏。
- 点击「新增」创建预设，设置名称、是否发送前确认；在表格添加、修改、删除步骤。
- **Text** 步骤发送 UTF-8 字节，按「换行」附加 None / CR / LF / CRLF。
- **Hex** 步骤发送精确的十六进制字节，例如 `01 03 00 FF`，必须将换行设为 `None`。
- **延时 ms** 是发送该步骤之后等待的毫秒数（0–60000）；每个预设最多 100 步，每步最大 4096 字节。
- 点击「保存预设」把配置写入现有 `%AppData%\SerialBridge\config.json` 中的 `CommandPresets`；升级保留。未保存的修改在关闭窗口后不会保留。
- 选择预设，点击「发送 / 运行宏」，可按配置先核对目标映射；运行中可点击「取消执行」。

## 安全与设计边界

宏只向**打开它的那条映射**发送数据，通过原有 `MappingRuntime.WriteLocal` 队列，不直接操作 COM 端口，也不修改 TCP 桥接链路。

- 仅在映射运行且串口已连接时发送。发送队列已满、串口断开或映射停止时立即中止剩余步骤。
- 所有步骤会在开始执行前完成编码和长度校验，避免运行到一半才发现 HEX 无效。
- 宏顺序入队，**不等待设备命令完成或 Shell 提示符**；延时只等待固定时间，不保证远端执行完成。
- 终端命令窗口为模态，防止用户同时在**该终端窗口**键入内容。但其他 TCP 客户端仍可能同时写串口，无法保证跨客户端不交错。
- 取消只阻止后续步骤；已经进入发送队列的字节不能撤回。
- 不会在本机执行预设文本为命令。文本编码目前固定 UTF-8。

建议首次调试时仅使用无破坏性的 `uname -a`、`dmesg | tail` 等命令；使用 `reboot`、`flash_erase` 等操作时保留发送前确认。
