# 串口终端快捷命令与宏

## 快捷命令栏（常驻显示）

打开映射的「串口终端」后，终端底部有一条 Xshell 风格的快捷命令栏，把已保存的预设显示为按钮，点击即发送，无需打开编辑窗口。

- 点击工具栏 **快捷命令 / 宏** 可显示或隐藏命令栏；显隐状态全局记忆（保存在 `%AppData%\SerialBridge\config.json`），重启后保持。
- 点击命令按钮**立即发送**，不弹确认窗：单步命令立即入队；多步宏按顺序执行，期间状态区显示进度，可点击 **停止** 中止后续步骤。
- 命令栏右侧 **编辑** 打开「快捷命令与宏」编辑窗口；保存预设后（窗口自动关闭），所有打开的终端命令栏自动刷新。
- 鼠标悬停按钮可查看内容摘要（文本/HEX、换行方式、宏步骤列表）。
- 点击发送后焦点自动回到终端，可继续手动输入。

## 编辑预设

点击命令栏 **编辑**（首次使用时按命令栏提示）进入编辑窗口：

- 一个预设包含一个步骤时即为常用命令快捷发送；包含多个步骤时按顺序运行宏。
- 点击「新增」创建预设、设置名称；在表格添加、修改、删除步骤。
- **Text** 步骤发送 UTF-8 字节，按「换行」附加 None / CR / LF / CRLF。串口控制台的回车是 **CR**——与键盘 Enter 等价；**LF / CRLF 仅个别特殊设备需要**，普通 Linux 控制台选 LF 可能出现输出错位或多余空提示符。
- **Hex** 步骤发送精确的十六进制字节，例如 `01 03 00 FF`；HEX 步骤的换行固定为 `None`（切换格式时自动设置，配置文件中的非法值加载时自动纠正）。
- **延时 ms** 是该步骤与下一步骤之间的等待毫秒数（0–60000，在下一步发送前等待）；最后一步的延时不会执行等待，编辑器中其单元格为禁用状态（已填数值保留，追加步骤后自动生效）。每个预设最多 100 步，每步最大 4096 字节。
- 点击「保存预设」或按 **Ctrl+S**：保存成功后窗口自动关闭，回到终端；保存失败时窗口停留并显示原因。
- 配置写入现有 `%AppData%\SerialBridge\config.json` 中的 `CommandPresets`；升级保留。关闭窗口即放弃未保存的修改。

## 安全与设计边界

宏只向**打开它的那条映射**发送数据，通过原有 `MappingRuntime.WriteLocal` 队列，不直接操作 COM 端口，也不修改 TCP 桥接链路。

- 仅在映射运行且串口已连接时发送。发送队列已满、串口断开或映射停止时立即中止剩余步骤；即使自动重连完成，也不继续发送后续步骤。
- 所有步骤会在开始执行前完成编码和长度校验，避免运行到一半才发现 HEX 无效。
- 宏顺序入队，**不等待设备命令完成或 Shell 提示符**；延时只等待固定时间，不保证远端执行完成。
- 命令栏执行宏期间，终端按键仍然逐键透传（可随时 Ctrl+C 中断远端程序）；宏与手动输入共享同一条 FIFO 发送队列。其他 TCP 客户端仍可能同时写串口，无法保证跨客户端不交错。
- 「停止」只阻止后续步骤；已经进入发送队列的字节不能撤回。命令点击即发送，请勿把 `reboot`、`flash_erase` 等破坏性命令配置为随手可点的快捷命令。
- 不会在本机执行预设文本为命令。文本编码目前固定 UTF-8。

建议首次调试时仅使用无破坏性的 `uname -a`、`dmesg | tail` 等命令验证链路，再逐步添加日常高频命令。
